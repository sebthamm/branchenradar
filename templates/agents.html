Feed
Quellen, die RSS- oder Atom-Feeds bereitstellen, liefern neue Inhalte als maschinenlesbare Liste — mit URL, Titel und Datum. Ein Fetcher abonniert diese Feeds deterministisch: Er ruft jeden konfigurierten Endpunkt ab, erkennt neue Einträge anhand ihrer ID oder ihres Datums und speichert sie als Rohkandidaten. Kein KI-Ermessen, vollständige Abdeckung, auditierbar pro Quelle.
⚙ Fetcher muss noch gebaut und so integriert werden, dass der Feed-Agent ersetzt wird.

{# ── SCRAPE ── #} {% set key = 'scrape' %}{% set ag = agent_configs.agents[key] %}{% set src_count = src_counts.get(key, 0) %}
Scrape
Quellen ohne Feed werden über ihre HTML-Übersichtsseiten überwacht. Ein Fetcher ruft dabei deterministisch die konfigurierten Endpunkte ab, extrahiert neue Links anhand stabiler Selektoren und speichert die Rohinhalte. Der Scrape-Agent übernimmt anschließend ausschließlich die inhaltliche Auswertung: Er bewertet, was der Fetcher geliefert hat, und formuliert daraus Signale — ohne selbst entscheiden zu müssen, welche Seiten er aufruft.
⚙ Fetcher muss noch gebaut und so integriert werden, dass er die erste Arbeit leistet und der Agent dann damit weiterarbeitet.

PDF
Viele Behörden, Kammern und Kassenärztliche Vereinigungen veröffentlichen relevante Inhalte ausschließlich als PDF — Beschlüsse, Rundschreiben, Richtlinien. Maschinelles Parsing ist hier unzuverlässig: Tabellen, mehrspaltige Layouts und eingebettete Listen lassen sich kaum strukturiert extrahieren. Der PDF-Agent liest diese Dokumente direkt und versteht Inhalt, Kontext und Relevanz — ohne vorgelagerten Fetcher.

{# ── SEARCH ── #} {% set key = 'search' %}{% set ag = agent_configs.agents[key] %}{% set src_count = src_counts.get(key, 0) %}
Search
Der Search-Agent ist grundlegend anders als die anderen drei: Er sucht aktiv nach Signalen, die in keiner der definierten Quellen stehen — über Suchmaschinen, Nachrichtenaggregatoren und offenes Web. Das ist per Definition nicht deterministisch und damit nicht durch einen Fetcher ersetzbar. KI ist hier die einzig sinnvolle Methode: Sie kann unbekannte Quellen entdecken, Relevanz einschätzen und neue Inhalte aus dem offenen Web in das Quelleninventar einspeisen.
