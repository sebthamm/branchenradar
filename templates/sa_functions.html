🔭 Radar-Dashboard
Signalübersicht nach Status Alle
Signale werden in 5 Phasen gruppiert: Handlungsbedarf, Angekündigt, In Entwicklung, Im Radar, Verfügbar / In Kraft. Statistische Zusammenfassung als Balken oben.
Volltext-Suche Alle
Echtzeit-Suche über Titel, Zusammenfassung, Detailtext und Quelle aller sichtbaren Signale.
Fachbereich-Filter Alle
Multi-Select-Dropdown in der Suchzeile — Mehrfachauswahl von Fachbereichen möglich. „Alle Fachbereiche" setzt zurück.
Kategorie-Filter Alle
Filter-Pills für Signal-Kategorien: Krankenkassen & GKV, Digitalisierung & TI, Gesetze & Regulatorien, Personal & Tarife, Praxismanagement.
Klappbare Signalkarten Alle
Klick auf eine Karte öffnet den Detailtext und den Quellen-Link. Status wird farblich durch einen Streifen und einen Chip kommuniziert.
Team-basierter Signalfilter Nutzer
Nutzer, die einem Team angehören, sehen ausschließlich die Signal-Kategorien, die dem jeweiligen Team zugewiesen wurden.
ToDo ableiten Admin
Button auf jeder Signalkarte öffnet ein Modal — Kategorie, Frist und Kommentar vergeben, optional direkt einem Nutzer zuweisen.
📡 Signaldatenbank
Vollständige Tabellenansicht Admin
Alle Felder tabellarisch: Titel, Status, Kategorie, Fachbereich, Quelle, Datum, Frist. Klapp-Detail mit Zusammenfassung, Detailtext und Aktionen. Spalten sortierbar.
Signal anlegen & bearbeiten Admin
Formular mit allen Feldern: Titel, Zusammenfassung, Detailtext, Status, Kategorie, Quelle (Name + URL), Datum, Frist, Fachbereiche.
Batch-Import per Paste Admin
Tabelle direkt aus Excel oder Google Sheets einkopieren (TSV). Automatische Erkennung des Trennzeichens (Tab, Semikolon, Komma).
Batch-Import per Datei-Upload Admin
CSV-Datei hochladen (UTF-8). Spaltenreferenz und Download-Vorlage auf der Import-Seite verfügbar.
Fachbereich-Zuweisung Admin
Signale können einem oder mehreren Fachbereichen zugewiesen werden. Entities sehen nur Signale, die ihren Fachbereichen entsprechen.
✓ ToDo-System
ToDo erstellen Admin
Aus jedem Signal ein ToDo ableiten — via Modal mit Kategorie, Frist, Kommentar und optionaler Nutzerzuweisung.
Nutzerzuweisung Admin
ToDos direkt beim Erstellen oder nachträglich aus der Liste einem Nutzer zuweisen. Zugewiesene ToDos erscheinen in der ToDo-Liste des Nutzers.
Benachrichtigungs-Badge Alle
Rotes Badge am „ToDos"-Menüpunkt: Für Nutzer bei neuer Zuweisung, für Admins wenn ein zugewiesenes ToDo erledigt wurde. Verschwindet beim Öffnen der Liste.
Erledigt mit Kommentar Alle
Klick auf das Häkchen öffnet ein Popup mit optionalem Kommentarfeld. Kommentar wird in der Admin-Ansicht als Rückmeldung angezeigt.
Überfällige ToDos Alle
ToDos mit überschrittener Frist werden mit rotem Rand und „⚠ Überfällig"-Label hervorgehoben.
Filter und Kategorien Alle
ToDo-Liste filterbar nach Offen / Erledigt und nach Kategorie. Kategorien je Entity konfigurierbar.
👥 Nutzer- und Entity-Verwaltung
Drei Rollenebenen Superadmin
Superadmin (systemweit), Admin (pro Entity), Nutzer (lesend + ToDos). Rollenbasierte Zugriffskontrolle auf alle Bereiche.
Entity-Verwaltung Superadmin
Entities (Praxen, Organisationen) anlegen, bearbeiten, löschen. Fachbereiche je Entity zuweisbar. Inline-Bearbeitung ohne Seitenwechsel.
Superadmin-Verwaltung Superadmin
Superadmins anlegen, bearbeiten und löschen. Eigener Account kann nicht gelöscht werden.
Nutzerverwaltung je Entity Admin
Admins können Nutzer in ihrer Entity anlegen und entfernen. Superadmins können alle Nutzer aller Entities verwalten.
Teams Admin
Nutzer können Teams zugewiesen werden (Standard: Team Abrechnung, Team Personal). Teams erhalten zugewiesene Signal-Kategorien.
📰 Quellen-Verwaltung
Quellen anlegen & bearbeiten Admin
Kürzel, Name, URL, Kategorie, Priorität, Status (Freitext) und Hinweise je Quelle erfassbar. Klick auf eine Zeile klappt das Bearbeitungsformular auf.
Prompt-Generierung Admin
Pro Quelle oder für alle aktiven Quellen auf Knopfdruck einen Recherche-Prompt generieren — inklusive allgemeiner KI-Hinweise und quellenspezifischer Hinweise. Copy-Button im Modal.
Batch-Import aus Excel Admin
Mehrere Quellen gleichzeitig importieren: Einfügen aus Excel oder Google Sheets (TSV), live Vorschau mit editierbaren Zellen, max. 20 Quellen pro Import.
Excel-Vorlage Admin
Download einer .xls-Vorlage mit korrekten Spaltenköpfen und einer Beispielzeile (Kürzel · Name · URL · Kategorie · Priorität · Status · Hinweise).
Allgemeine KI-Hinweise Admin
Freitextbereich für übergreifende Anweisungen an die KI, die in jeden generierten Prompt eingebettet werden.
Hinweise-Spalte in der Tabelle Admin
Quellenspezifische KI-Hinweise sind direkt in der Tabellenübersicht sichtbar (gekürzt auf 2 Zeilen, voller Text als Tooltip).
⚙ Einstellungen & Technik
ToDo-Kategorien konfigurieren Admin
Jede Entity kann eigene ToDo-Kategorien definieren. Standard-Kategorien werden beim Anlegen neuer Entities vom Superadmin-Template übernommen.
Standard-Kategorien (Vorlage) Superadmin
Superadmin definiert Standard-ToDo-Kategorien, die automatisch bei der Erstellung neuer Entities übernommen werden.
Datenpersistenz Superadmin
Alle Daten (Signale, Nutzer, Entities, ToDos) werden als JSON-Dateien auf dem Server gespeichert — kein Datenbank-Server erforderlich. Deploys überschreiben keine Laufzeitdaten.
Webhook-Deployment Superadmin
Code-Updates werden per HTTP-POST-Webhook ausgelöst (git pull + Gunicorn-Reload). Kein manueller Server-Zugriff nötig.
Dunkles / Helles Design Alle
Automatische Theme-Erkennung via prefers-color-scheme. Manueller Toggle im Browser überschreibt die OS-Einstellung.
